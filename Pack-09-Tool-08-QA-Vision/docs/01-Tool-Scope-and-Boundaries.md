# 01 — Tool Scope and Boundaries

QA Vision trả lời: **video thực tế có tuân thủ các contract upstream hay không?**

Owns:
video review, frame/timecode analysis, contract comparison, issue classification, evidence, scores, pass/fail, correction targets.

Does not own:
prompt rewriting, regeneration, camera/motion/environment/cinematic planning, ProductDNA editing.
